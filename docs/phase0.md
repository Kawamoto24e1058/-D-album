# Phase 0 品質検証の手順

## 準備

1. サンプル写真を10枚用意する（人物・風景・室内・逆光・夜景・集合写真を含める）
   - `samples/` に置いてもコミットされない（`.gitignore` 済み）
2. 起動する
   ```sh
   npm ci --ignore-scripts
   npm run dev                      # PC
   HTTPS=1 npm run dev -- --host    # スマホ実機（ジャイロには HTTPS が必要）
   ```
   スマホでは自己署名証明書の警告が出るので、許可して進む

## 採点

1. 「写真を追加」で10枚を選ぶ。初回はモデル（PC 約50MB、スマホ 約19MB）をダウンロードする
2. 写真ごとに視点を動かして、4項目を1〜5で採点する（5 = 気にならない）
   - 輪郭の引き伸ばし / 背後の穴 / 顔の歪み（顔がなければ「顔なし」） / 奥行きの自然さ
3. 「表示パラメータ」で奥行きの強さと移動範囲を変えたときは、その値も記録される
4. 10枚を終えたら「CSVをダウンロード」し、`docs/phase0-results/` に保存する
5. 気になった写真はスクリーンショットを撮る

## 計測値

画面右上に表示される値を、採点表に自動で記録します。

| 項目 | 意味 |
|---|---|
| backend / dtype | `webgpu` か `wasm`、モデルの精度 |
| モデル読込 | 初回はダウンロード時間を含む。2回目以降はキャッシュから読む |
| 推論 | 深度推定だけの時間 |
| 追加→表示 | ファイル選択から3D表示まで。成功基準（PC 5秒、スマホ 15秒）と比べる値 |
| fps | 30 を下回ると描画解像度を自動で下げる |

## 合格ライン（仮）

平均3以上の写真が7枚以上。未達の場合は、移動範囲を狭める、対象の写真を絞る、などで調整し、結果と合わせて報告する。

## 報告に含めるもの

- 採点表（CSV）
- 端末ごとの計測値（PC と Android、可能なら iPhone）
- スクリーンショット
- 合格ラインを見直す必要があるかどうかの所見
